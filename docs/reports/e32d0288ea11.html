智以智用，始于云栖。 2026年，中国AI产业关心的问题正在从底层技术向上层业务转移。 前两年，大家都在比参数、比谁的模型更聪明。而今年客户的问题明显务实了很多。他们不再只关心模型参数，而是算力是否稳定、价格多少、模型能否真正可用，AI是否能够进入经营现场和产业上下游。 显然，今天的AI正从“能力演示”走向“规模应用”，从“模型规格与单点能力的竞赛”，迈向“智能体规模化应用”的新阶段。 这一步跨得不算轻松。当AI从一次性的问答，走向持续的推理和任务执行，成本、架构、生态、组织治理这几道难题会被同时放大。它们考验的已经不是模型的上限，而是AI能不能真正成为可交付、可复制、算得过账的生产力。 这些是产业级的问题，需要一个产业级的场合来集中回答。 9月22日至24日，2026云栖大会将在杭州举行。 今年的云栖大会，无论是内容体量还是嘉宾规模，都是前所未有的。 作为长期观察中国云计算与智能化的舞台，云栖大会今年把主题定为「智以致用」，以Agentic AI为核心锚点，串起芯片、云基础设施、模型能力与模型服务、Agentic应用的完整链路，直抵生产方式的深层变革。大会设置3大主论坛、120余场分论坛，2000余位国内外重磅嘉宾将带来前沿观点。 从算力到价值，这条链路怎么打通、AI的大规模落地又该往哪走，就是今年云栖想回答的问题。 1.智以致用，从“炫技”到“兑现价值” 2026云栖大会以「智以致用」为主题，设3大主论坛、共四场，从战略、技术、产业、社会四个维度，回应同一个命题：AI大规模进入生产环境之后，价值如何创造，又在哪里兑现。 云栖大会主论坛是这场大会的全景入口。 9月22日上午，管理层将在云栖大会主论坛现场发表主旨演讲，发布模型与基础设施的重磅进展，邀请行业龙头分享智能化实践，呈现五层全栈技术体系从算力到价值的全链路，完整摆到台面上。 价值全链路，需要领先的技术承接。9月22日下午，两场技术主论坛同时召开，为我们呈现阿里云在AI方面的技术探索。 一场是MaaS&Agent，围绕“创造Token、成就Agent、交付生产力”这条主线，呈现阿里巴巴从模型内核到产业生产力的MaaS战略图景。 千问AI平台将展示模型服务与智能体服务基座能力的最新演进，千问办公、Qoder、千问APP分别围绕企业办公、AI Coding与面向大众的通用场景发布全新版本。 论坛还将发布Qwen Intelligence手机智能解决方案，邀请多行业客户畅聊模型与行业的下一步方向，最后以生态为落脚，发布伙伴激励计划。从基座能力到产品落地，从行业结合到生态繁荣，这场论坛几乎把阿里巴巴MaaS在Agentic时代的战略路径走了一遍。 另一场是Agentic Cloud，聚焦从算力供给到智能体运行环境的云基础设施全面升级。 在阿里云看来，AI正从“模型规格与单点能力竞赛”，迈向“智能体规模化应用”的新阶段。智能体真正走向生产，离不开模型能力、Agent Harness与上下文工程的协同演进。 面向Agentic时代，阿里云提出Agentic Cloud，推动云从“面向人的工具集合”，升级为“为Agent而生的操作系统”。 本论坛将系统呈现阿里云面向智能体时代的基础设施布局：以AI Native加速模型训练与推理，以Agent Native支撑智能体的构建与运行，以Data Plane承载模型训推所需的数据，以及智能体持续运行所需的上下文。 同时，论坛还将汇聚全球AI领域的领军人物，共话智能体产业的前沿趋势与未来图景。 在云栖主论坛和两场技术主论坛外，今年的云栖还特别设置了“无法计算的价值”主论坛，把视角从技术转向人和社会。 “无法计算的价值”主论坛围绕AI与社会的共生、共治、共善三重命题展开，探讨技术在教育、医疗、基层治理等领域的普惠实践。在阿里云看来，当AI逐渐变成新的基础设施，衡量它的尺度，不该只有算力、效率和成本。 四场主论坛，一条主线：智以致用。不止于技术突破，更在于价值抵达。这也是今年云栖最想把话说清楚的地方。 2. 120余场分论坛，构成AI的完整链路 AI正从能力演示走向规模应用。企业与开发者的关注点，逐步转向：如何获得稳定高效的算力，把模型转化为可用产品，让AI真正进入研发、经营与产业现场。 今年云栖大会将沿三大线索，于9月22日至24日集中呈现120余场分论坛。 第一条线索，重塑计算底座——让AI更高效、更稳定地进入生产。 随着AI从单次问答走向持续推理与任务执行，计算底座正面临一次系统性升级。 芯片与算力分论坛聚焦芯片、服务器、超节点和智算中心，回应大规模训练与推理对计算密度、互连效率、散热能耗和交付速度的新要求，通过软硬一体化、液冷、高压直流和数字化运维，探索高效可靠的智能算力供给。 而AI Native Cloud讨论存储、缓存、网络、边缘智能和AI平台，目标是提升集群利用率和Token传输效率，缩短模型从开发验证到规模服务的工程路径。 Agent Native Cloud则聚焦智能体的构建、托管与治理，覆盖智能体构建平台、安全沙箱、运行隔离、上下文、记忆管理和多模态数据，探讨智能体如何走向安全、稳定的企业级部署。 云与基础设施聚焦AI与Agent时代的云底座全栈重构：从弹性算力、龙蜥操作系统到为Agent重做的一体化湖库与多模数据层，从边缘云、视频云、云通信到专有云与AI云治理，并前瞻算电协同与太空计算，让云更弹性、数据更统一、系统更智能、上云更可信。 第二条线索，探索智能边界——从模型能力走向可用生产力。 模型价值正在从“是否聪明”转向“能否完成工作”。模型前沿分论坛聚焦推理、多语言、多模态及视听生成，展示模型能力如何进入游戏、影像、设计和内容生产。 Agentic Coding分论坛关注AI编程从补全走向开发交付，讨论代码验证、研发管线及效率、质量与安全，试图给开发者提供可复制的打法。 Agentic应用分论坛则盯着智能体在办公、协同和应用开发中的规模落地，关注Skill、知识检索、记忆、工具调用与多智能体协作，展现智能体如何承担完整任务并融入组织流程。 推理服务分论坛解决Token供给、推理加速、训练微调和模型管理，让企业更便捷地部署和运营模型能力。 围绕汽车、金融、游戏、短漫剧的行业共创分论坛，讨论模型如何安全进入业务流程； 开源与社区分论坛则用开放的模型、工具、框架，降低创新门槛。这一整条线索的落点很明确：把模型能力变成可构建、可部署的生产力。 第三条线索，催生万业新局——让AI在真实业务中创造价值。 AI的价值最终要由业务结果验证。围绕财务、研发、运营和服务等关键环节，分论坛探讨如何选择高价值场景、推动试点走向规模应用、持续衡量投入产出，并同步调整流程、组织、人才与治理机制。 “创造者状元秀”分论坛聚焦阿里云内部职能团队用AI解决真实问题，以财务、法务等场景为切口，看智能体如何承接复杂执行、验证投入产出，把人的时间释放出来，让判断、洞察和战略回到价值创造的前台。 组织进化分论坛回答流程如何改变、人如何协作、价值怎样衡量； 全球化分论坛关注企业如何借助全球基础设施与开放模型出海增长； 产业数智转型分论坛呈现AI与实体产业融合的一线经验； AI治理与人文价值分论坛则把数据隐私、模型与智能体风险、技术公平、伦理和社会责任摆上桌。 三条线索串联起今年云栖的一个特点：它把“从芯片到业务结果”当成一件事来讲，而不是把算力、模型、应用拆成三场各说各话。这就是阿里云AI的价值链。 3大主论坛、120余场分论坛，2000余位国内外重磅嘉宾，显然，今年的云栖大会，会让9月的杭州再次成为全球AI产业重要的观察窗口。 今年云栖大会不只是一次展会。对找答案的产业领袖、抓机会的创业者、探舞台的开发者来说，它提供的是同一个视角：看AI怎么从“炫技”，一步步走到“生产力”，再走到可衡量的价值兑现。 一条以Agentic AI为锚点的完整链路，四场不同维度的主论坛，120余场把细节填满的分论坛。今年云栖真正想回答的，是一个比“谁的模型更强”更朴素、也更难的问题：AI进了生产环境之后，价值到底在哪里被创造，又在哪里被兑现。 从算力到模型，从模型到Agent，再从Agent到业务现场的结果，2026云栖大会想把这些环节连成一条能走通的路。 智以致用，始于云栖。 （封面图来源：云栖大会）
